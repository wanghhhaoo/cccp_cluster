# 三类推理任务的接入与复验

集成基线为 CCCP 协议 3、提交 `e469a52`；评审修复后协议升为 4（`algorithms_ready` 扩到 5 位），见 `docs/DESIGN.md`“实现时的调整”第 12～19 条。调度器用现有节点能力位分配任务，执行器用单独进程运行每个算法。保留原 PKCI/PKCT 两个位。所有网关和执行节点使用同版代码。

## 节点配置

| 任务 | 执行节点环境 | 样例范围 |
|---|---|---|
| FASTLIVO | Linux、Docker 客户端、已载入 `lamm_full:v1`、`FASTLIVO_BAG` 指向已录制 bag 的绝对路径 | 默认使用包内 Avia 激光雷达与 IMU，输出带强度的 PCD。彩色模式另设 `FASTLIVO_CONFIG_DIR`，其中提供本机已标定的 `avia.yaml` 和 `camera_pinhole.yaml`。样例图像 1440×1080。镜像为 amd64。 |
| RSSMAP | `RSSMAP_PYTHON` 指向装好传播模型 wheel 和依赖的 Python，`RSSMAP_DATA` 指向解压后的 `demo_data/newdata`，样例需可用 CUDA | `params.tx` 指定发射机，`params.score` 开启与测点比对。输出 `rss.npz`，评分在同目录的 `run.log`。 |
| HETEROMAP | 六个节点均配置 `HETEROMAP_ROOT`、`HETEROMAP_PYTHON`、`CCCP_JOB_STORE`。Python 需能导入原包及 pyquaternion。`COLLAB_DEVICE` 选 CPU 或 CUDA | 固定使用包内 town3 验证序列的 20 帧。指定六个互异节点，依次为融合节点、id_0 至 id_4。 |

所有执行器使用 util-linux 的 `setpriv`。在各节点和提供下载的网关上将 **同一可写共享文件系统** 挂载到 `CCCP_JOB_STORE`（如 NFS），支持同目录原子重命名。单节点默认在用户目录的 `cccp_jobs`。每个任务按 UUID、epoch、assign_term、角色隔离。HeteroMap 用共享目录传结构特征和上下文，每帧每架机上、下行各约 32 MiB，局部状态留在本机。成功消费后移除中间张量。缺少预期包默认等待 180 秒，可设 `HETEROMAP_TIMEOUT`。共享目录仅对可信执行节点开放写入。

FASTLIVO 节点需能调用 Docker。挂载的 bag、结果目录与适配脚本路径必须在 Docker 守护进程所在主机上也有效。将该执行器运行在安装了 ROS 2 Humble 的 Linux 主机上可直接满足路径约定。包内相机分辨率与当前 bag 不匹配，彩色模式请提供实际内外参。仅在持有 bag 的节点上声明 FASTLIVO，同一集群有多个 bag 时用 `request_node` 选择。

传播模型原包配置有三项绝对路径。在**解压的运行副本**中，从 `demo_data/newdata/config` 运行以下一次性准备命令，迁移目录后再执行一次。wheel 用该节点专用 Python 安装。

```bash
python - <<'PY'
import json
from pathlib import Path
p = Path("config.json")
cfg = json.loads(p.read_text())
for key in ("receiver_positions", "transmitter_positions", "rssi_csv"):
    target = Path(Path(cfg[key]).name).resolve(strict=True)
    cfg[key] = str(target)
p.write_text(json.dumps(cfg, indent=2))
PY
```

## 调用与产物

向任意网关的 `POST /api/ue/tasks` 提交下列 JSON 中的一条。节点名按实际部署修改。

```json
{"task_type":"FASTLIVO","request_node":"edge-01","idempotency_key":"bag-demo-1"}
```
```json
{"task_type":"RSSMAP","request_node":"edge-02","params":{"tx":"node_7","score":true},"idempotency_key":"rss-demo-1"}
```
```json
{"task_type":"HETEROMAP","mode":"fusion","target_nodes":["edge-01","edge-02","edge-03","edge-04","edge-05","edge-06"],"idempotency_key":"bev-demo-1"}
```

用返回的 task_id 查询 `GET /api/ue/tasks/<task_id>`。完成后在同一网关读取 `result_url`，返回的 `files` 列出逐文件下载地址。HeteroMap 的 120 个 NPZ 包括 20 张全局地图和五架机各 20 张局部地图。FASTLIVO 输出 PCD，RSSMAP 输出含 prediction_dbm 的 NPZ。运行中可用 `DELETE /api/ue/tasks/<task_id>` 取消。失败时看查询中的 error_message，再读该代次对应角色的 run.log。退出后在共享盘保留产物，恢复或重复请求不会覆盖旧代次。
